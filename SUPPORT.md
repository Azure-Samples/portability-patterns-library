# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/Azure-Samples/portability-patterns-library/issues)
to track bugs, feature requests, and questions about the samples and portability
patterns. Search existing issues before opening a new issue to avoid duplicates.

For help, review the [project README](./README.md) and the
[Order Management sample documentation](./samples/OrderManagementApp/README.md).
If you still need assistance, open an issue describing your question or problem.
Include the sample, target environment, tool versions, reproduction steps, and
relevant logs. Remove secrets, credentials, tokens, and personal data before posting.

For security vulnerabilities, follow [SECURITY.md](./SECURITY.md) instead of opening
a public issue.

## Microsoft Support Policy

Support for the Portability Patterns Library is limited to the resources listed
above. These resources are reference and sample implementations, not production
workloads.
